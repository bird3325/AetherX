개인정보처리방침 (Privacy Policy)

최종 수정일: 2026년 9월 2일

1. 개요

본 개인정보처리방침은 셀러보드X (AetherX) (이하 "확장프로그램")가 이용자의 개인정보 및 데이터를 다루는 방식을 설명합니다.

🔒 핵심 원칙 (Local-First & Privacy First):
셀러보드X는 이용자의 개인식별정보(PII)를 수집, 저장, 전송하거나 외부 서버로 공유하지 않습니다. 모든 분석 및 사용자 설정값 처리는 브라우저 내부(로컬 환경)에서만 독립적으로 실행됩니다.

2. 수집 및 처리하는 데이터

확장프로그램은 어떠한 형태의 개인정보도 수집 및 외부 서버로 전송하지 않습니다.

  • 수집하지 않는 정보: 성명, 이메일, 전화번호, IP 주소, 브라우징 방문 기록, 개인 식별자 등
  • 로컬 저장 데이터 (chrome.storage.local):
    • 사용자가 직접 설정한 마진 계산 관련 옵션 (기본 마진율, 커스텀 수수료 설정값)
    • 화면에서 선택한 빠른 상품 비교 목록 (Quick Compare 데이터)
    • 데이터 로딩 속도 향상을 위한 브라우저 내 임시 캐시

3. 브라우저 권한 사용 목적

확장프로그램은 서비스 제공을 위해 최소한의 권한만을 요구하며 목적 외 사용을 하지 않습니다.

  • Storage (`chrome.storage.local`): 사용자 설정값 및 임시 비교 목록 데이터를 이용자의 브라우저 내에 안전하게 보관하기 위해 사용합니다.
  • ClipboardWrite (`clipboardWrite`): 사용자가 정밀 마진 계산 결과, 원가 데이터 및 핵심 키워드를 복사하여 외부 문서(Excel 등)에 붙여넣을 수 있도록 편리한 원클릭 복사 기능을 지원하기 위해 사용합니다.
  • Host Permissions (호스트 권한): 네이버 쇼핑, 쿠팡, G마켓, 옥션, 1688, 알리익스프레스 등의 공개 상품 페이지 DOM을 파싱하여 실시간 오버레이 분석 지표(판매량 추정, 마진율 등)를 화면에 표시하기 위해서만 사용됩니다.

4. 데이터 제3자 제공 및 매매 금지

셀러보드X는 수집하는 개인 데이터가 없으므로, 이용자의 데이터를 제3자에게 판매, 대여, 교환, 전송하거나 마케팅 목적으로 활용하지 않습니다.

5. 쿠키 및 추적 기술

본 확장프로그램은 이용자를 추적하기 위한 쿠키(Cookies), 웹 베콘(Web Beacons) 또는 제3자 타겟팅 분석 스크립트를 사용하지 않습니다.
