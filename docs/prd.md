# Aether X (구 SellerLens) 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요 (Project Overview)
* **제품명**: Aether X (에테르 엑스)
* **플랫폼**: Chrome / Edge Extension (Manifest V3 기반)
* **지원 마켓**: 네이버 쇼핑(스마트스토어), 쿠팡(로켓배송/제트/윙)
* **타겟 사용자**: 월 매출 500만 원 ~ 5,000만 원 구간의 국내 중급 사입·위탁·PL 셀러 (1~2인 소규모 운영팀)
* **핵심 가치**:
  * **Clean Overlay**: 브라우징 속도를 저하시키지 않고 검색 결과에 핵심 지표 5가지를 즉시 표시.
  * **신뢰 구간 매출 추정**: 오차가 큰 단일 수치 대신 범위와 신뢰도(%)를 제공하여 재고 리스크 최소화.
  * **스마트 필터 & 빠른 비교**: 탭을 여러 개 열지 않고도 조건 충족 상품을 즉시 하이라이트하고 최대 5개 상품 동시 비교.
  * **원클릭 소싱 인텔리전스**: 1688 이미지 역검색 및 관부가세·플랫폼 수수료가 즉시 계산되는 마진 시뮬레이션.

## 2. 사용자 페르소나 및 핵심 User Journey
### 2.1 페르소나
* **김셀러 (33세, 네이버/쿠팡 2년 차 사입 셀러, 월 매출 2,500만 원)**
  * **Pain Point**: 기존 올인원 툴은 가격이 비싸고 무거우며, 화면 전체를 덮는 팝업 때문에 쇼핑몰 탐색 흐름이 끊김. 수치 오차가 커서 늘 엑셀로 여러 지표를 재계산해야 함.
  * **Needs**: 검색 화면에서 마진 25% 이상, 리뷰 증가 속도가 빠른 유망 상품만 한눈에 확인하고, 1688 원가를 바로 대조하여 소싱 결정을 내리고 싶음.

### 2.2 핵심 User Journey
1. **네이버/쿠팡 검색어 입력** (예: '캠핑 랜턴')
2. **검색 결과 내 'Aether X Clean Overlay' 즉시 렌더링** (판매량 범위, 마진, 리뷰속도)
3. **스마트 퀵 필터 작동**: "마진 30% 이상 + 리뷰 100~500개 + 로켓 제외" 하이라이트
4. **유망 상품 3개를 Drag & Drop으로 'Quick Compare' 사이드 도크에 추가**
5. **원클릭 1688 이미지 역검색 실행** → 실시간 마진 계산 확인 후 맞춤 CSV 다운로드

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 검색 결과(SERP) Clean Overlay & 신뢰 구간 추정 (P0 - MVP)
* **F-01: SERP Clean Overlay**
  * 검색 결과 상품 카드 하단에 1줄 초소형 데이터 바 삽입.
  * 노출 항목: 월 판매량 범위(신뢰도), 예상 마진율, 30일 리뷰 속도, 배송/스토어 등급 배지, 1688 퀵 버튼, 비교 담기(+).
* **F-02: 신뢰 구간 추정 로직**
  * 단순 판매량 숫자가 아닌 `420 ~ 580개 (81% 신뢰도)` 형태로 노출.
  * 최근 30일 리뷰 등록 빈도, 찜/구매건수, 가격 변동 추이 가중치 반영.
  * 'i' 아이콘 호버 시 산출 근거 툴팁 제공.
* **F-03: 스마트 퀵 필터 바**
  * 검색 결과 상단 플로팅 툴바에서 조건 설정.
  * 조건: 마진 N% 이상, 리뷰 수 범위, 평점 이하, 로켓배송 여부 등.
  * 부합 상품은 하이라이트 테두리 부여, 비부합 상품은 투명도(Opacity 40%) 처리.
* **F-04: Quick Compare 미니 도크**
  * 우측 하단 고정 도크에 상품을 Drag & Drop하거나 `+` 클릭 시 최대 5개 상품 핵심 지표(가격, 마진, 판매량, 리뷰속도) 가로 대조.

### 3.2 상세 페이지 분석 & 소싱 마진 계산기 (P0 / P1)
* **F-05: 상세 오버레이 패널**
  * 화면 우측 슬라이드 패널 (접힘: 40px 토글 / 펼침: 360px).
  * 핵심 지표 카드 (추정 월매출, 옵션별 판매 비중, 90일 가격 변동).
* **F-06: 원클릭 소싱 역검색**
  * 상품 대표 이미지를 클릭 한 번으로 1688, 타오바오, Google Lens 새 탭으로 검색.
  * Quick Compare 도크에서 5개 상품 일괄 역검색 지원.
* **F-07: 국내 맞춤 정밀 마진기**
  * 플랫폼 수수료(스마트스토어 2~5.63%, 쿠팡 카테고리별 수수료) 자동 매칭 + 1688 위안화 소싱가 입력 시 환율, 관부가세, 배송비를 반영한 실질 순이익 산출.
* **F-08: 경량 CSV 다운로드**
  * 화면에 표시된 핵심 컬럼(선택 가능)만 정리하여 UTF-8 CSV로 즉시 추출.

### 3.3 리뷰 인텔리전스 & 이상 징후 감지 (P1 / P2)
* **F-09: 부정 리뷰 키워드 클러스터** (P1)
  * 1~2점 부정 리뷰에서 자주 나타나는 불만 단어(품질, 마감, 배송 등) TOP 3 추출.
* **F-10: 실시간 이상 징후 알림** (P1)
  * 가격 급락(최저가 출혈 경쟁), 재고 급감(품절 임박), 비정상 리뷰 급증(어뷰징 의심) 시 경고 태그 부착.
* **F-11: Top 10 키워드 갭** (P2)
  * 상위 10개 상품 제목 및 옵션에서 누락된 핵심 키워드 빈도 추출.

## 4. 비기능 요구사항 (Non-Functional Requirements)
* **성능 및 반응 속도**:
  * DOM 파싱 및 Clean Overlay 렌더링 시간 < 250ms.
  * Intersection Observer 기반으로 뷰포트 내 상품만 렌더링하여 메모리 점유율 최소화 (< 40MB).
* **보안 및 규정 준수**:
  * 쇼핑몰 이용약관을 준수하여 비인가 API 호출을 차단하고 공개 HTML DOM만 파싱.
* **Local-First 원칙**:
  * 모든 분석 데이터와 사용자 설정값은 `chrome.storage.local`에 우선 저장.
