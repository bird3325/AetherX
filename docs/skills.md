# Aether X 개발 및 운영 스킬셋 (Skills)

본 문서에서는 Aether X 확장프로그램 내에서 작동하는 각 서브에이전트(Sub-agent) 및 모듈들의 기능적 역할과 구현 규격을 정의합니다.

## 1. DOM 파싱 스킬 (DOM Parsing Skill)
* **네이버 쇼핑 파서 (Naver Shopping Parser)**:
  * 네이버 쇼핑 검색 결과 페이지(SERP)에서 개별 상품 아이템 요소를 탐색하고 구조화합니다.
  * 추출 항목: 상품 ID, 상품명, 상품 이미지 URL, 가격, 리뷰 수, 찜 수, 스토어 등급(빅파워, 프리미엄 등), 등록일, 스마트스토어 상세 URL.
* **쿠팡 파서 (Coupang Parser)**:
  * 쿠팡 검색 결과 페이지(SERP)에서 개별 상품 아이템 요소를 구조화합니다.
  * 추출 항목: 상품 ID, 상품명, 상품 이미지 URL, 가격, 리뷰 수, 평점, 로켓배송 배지 여부, 상세 URL.

## 2. 판매량 및 신뢰도 추정 스킬 (Sales Estimation Skill)
* **신뢰 구간 연산 모듈**:
  * 리뷰 증가율(최근 30일), 평점, 찜 수, 가격 변동 추이 등을 기반으로 월 추정 판매량 범위와 신뢰도(%)를 산출합니다.
  * 추정식 공식 예시 (가중치 기반):
    * `기본 판매량 = 최근 30일 리뷰 수 * 리뷰 작성 비율 보정치 (예: 10 ~ 15배)`
    * `신뢰 구간 하한 = 기본 판매량 * 0.8`
    * `신뢰 구간 상한 = 기본 판매량 * 1.2`
    * `신뢰도 = 80% + (리뷰 수에 비례한 가중치, 최대 95%)`

## 3. 소싱 및 마진 계산 스킬 (Sourcing & Margin Calculation Skill)
* **1688 이미지 검색 연동**:
  * 상품 대표 이미지 URL을 이용해 타오바오/1688 이미지 검색 URL을 동적으로 생성하여 새 탭으로 오픈합니다.
* **마진 시뮬레이터**:
  * 스마트스토어/쿠팡 카테고리 수수료, 1688 위안화 소싱 가격, 실시간 환율(API 또는 고정 모크), 관부가세(기본 8~10%), 국내외 배송비를 반영하여 마진율을 실시간으로 계산합니다.

## 4. 데이터 저장 및 비교 스킬 (Data Storage & Comparison Skill)
* **Chrome Local Storage 연동**:
  * `chrome.storage.local`을 이용해 사용자가 비교 도크에 담은 최대 5개의 상품 데이터를 캐싱하고 상태를 유지합니다.
* **CSV 데이터 내보내기**:
  * 선택된 컬럼에 대응하는 데이터를 UTF-8 CSV 문자열로 인코딩하여 다운로드 링크를 제공합니다.
